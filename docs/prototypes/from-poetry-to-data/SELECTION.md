# Prototype selection

No winner has been selected.

Choose one direction or define a concrete hybrid:

- `A — narrative`: the homepage starts with the question of change across thirteen centuries.
- `B — explorer`: search and entity exploration are the first action.
- `C — research`: findings, evidence, method, and downloads lead.
- `D — audience`: distinct paths lead general readers, literary researchers, and data researchers.

A valid hybrid decision names the default homepage direction and the borrowed elements, for example: `A as the homepage, B for the atlas entry, and C's evidence ledger on research pages`.

After selection, run `to-spec`. Do not copy disposable prototype markup into production before the specification is approved.
