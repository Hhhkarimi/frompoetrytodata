# Issue tracker

## Provider

GitHub Issues for `Hhhkarimi/frompoetrytodata`.

## Workflow

- Search open and closed issues before creating a new one.
- The issue number is the stable work reference and should be cited by specifications and implementation reports.
- Use `gh` or the GitHub UI/API when authenticated access is available.
- Do not create a local substitute issue without explicit approval when GitHub access is unavailable.
- Pull requests are not the default intake surface.

## Current environment note

The artifact-building environment used for this package had public read access to the repository and deployed website, but no authenticated GitHub write connector and no working direct `git clone`. No issue was created or modified from this environment.
