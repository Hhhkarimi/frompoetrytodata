# از شعر تا داده

**اطلس تعاملی و چندصفحه‌ای تحلیل داده‌های شعر فارسی — کاری از حسین کریمی**

«از شعر تا داده» یازده مطالعهٔ پژوهشی را برای مخاطب عمومی، پژوهشگر ادبیات و داده‌کاو در یک تجربهٔ بصری فارسی ارائه می‌کند. نسخهٔ ۷ یک مسیر تازه برای مخاطب کنجکاو دارد: ده پرسش ساده و گفت‌وگوساز که پاسخشان مستقیماً از پیکرهٔ اصلی محاسبه شده و در کنار هر عدد، روش و محدودیت تفسیر را هم نشان می‌دهد.

## فصل‌های پژوهش

1. رودخانهٔ تحول مضامین شعر فارسی
2. تولد، خاموشی و دگرگونی استعاره‌ها
3. نقشهٔ پیوندهای متنی و شباهت شاعران
4. تشخیص سدهٔ شعر با هوش مصنوعی
5. اثر انگشت سبکی و کشف شعرهای نامتعارف
6. مقایسهٔ تکامل غزل، قصیده، رباعی و مثنوی
7. جغرافیای تخیل و مهاجرت شعر فارسی
8. نیمه‌عمر واژگان در شعر فارسی
9. سنجش انتساب شعر با شواهد زبانی، فکری و تاریخی
10. ده پرسش جذاب از هزار سال شعر فارسی
11. زیبایی‌شناسی محاسباتی و ده بیت منتخب هر شاعر

## پرسش‌های عمومی نسخهٔ ۷

- در شعر فارسی «دل» بیشتر حرف می‌زند یا «عقل»؟
- شعر فارسی شب‌دوست‌تر است یا روزدوست؟
- آیا نشانه‌های غم واقعاً از شادی بیشترند؟
- شاعران بیشتر از «من» می‌گویند یا «ما»؟
- پرسشگرترین شاعر پیکره کیست؟
- شعر بیشتر در گذشته زندگی می‌کند، اکنون یا فردا؟
- تصویر حرکت و راه بیشتر است یا خانه و وطن؟
- محبوب‌ترین خانوادهٔ رنگی در شعر چیست؟
- کدام پرنده در آثار شاعران بیشتری پرواز می‌کند؟
- کدام نام جغرافیایی میان شاعران مشترک‌تر است؟

این پرسش‌ها با شمارش نرمال‌شده، میانگین شاعرمتوازن، پنجرهٔ واژگانی و رتبه‌بندی پوشش شاعر پاسخ داده می‌شوند. واژه‌های جغرافیایی بسیار مبهم مانند «چین»، «روم»، «شام» و «ری» از رتبه‌بندی حذف شده‌اند. خروجی‌ها توصیفی‌اند و جای خوانش نزدیک، تحلیل معنایی یا داوری تاریخی را نمی‌گیرند.

## ویژگی‌های نسخهٔ ۷

- بخش تعاملی «ده پرسش جذاب» با ده تب، پاسخ کوتاه، معیارهای کلیدی و نمودار پویا
- دکمهٔ «پرسش بعدی» برای گردش سریع و تجربهٔ مناسب مخاطب عمومی
- پاسخ مبتنی بر ۵۴٬۵۱۱ رکورد پالایش‌شده و بیش از ۹٫۷ میلیون واژه
- نمایش هم‌زمان عدد، روش محاسبه، نکتهٔ تفسیری و «ترمز اغراق» برای هر پرسش
- مقایسهٔ دل/عقل، شب/روز، غم/شادی، من/ما، گذشته/اکنون/فردا و راه/خانه
- رتبه‌بندی شاعران پرسشگر با حداقل ۲۰ هزار واژه برای جلوگیری از رتبه‌های کم‌نمونه
- رتبه‌بندی رنگ‌ها، پرندگان و جغرافیا با شمار رخداد و پوشش شاعران
- تحلیل زمینهٔ شب و روز با پنجرهٔ هشت‌واژه‌ای، نه فقط شمارش خام
- تولید خودکار JSON و CSV پرسش‌ها از فایل اصلی پیکره
- صفحهٔ پژوهشی مستقل، کارت OG، API، دادهٔ دانلودی و متادیتای قابل ایندکس
- حفظ تمام بهبودهای نسخهٔ ۶: تجربهٔ ساده/پژوهشی، واژه‌نامه، نقشهٔ پیوند متنی و آزمایشگاه انتساب

## اجرای محلی

نیازمند Node.js نسخهٔ ۲۲ و Python 3:

```bash
npm install
npm run dev
```

ساخت نسخهٔ تولیدی و ممیزی SEO/GEO:

```bash
npm run build
npm run seo:audit
npm run preview
```

## تولید دوبارهٔ پژوهش‌های مبتنی بر TSV

```bash
npm run data:attribution
npm run data:public-questions
```

یا هر دو با یک دستور:

```bash
npm run data:research
```

خروجی‌های پرسش‌های عمومی:

```text
src/data/publicQuestionsResearch.json
public/downloads/public-questions-analysis.csv
```

خروجی‌های پژوهش انتساب:

```text
src/data/attributionResearch.json
public/downloads/attribution-corpus-audit.csv
```

فایل خام باید در مسیر زیر باقی بماند:

```text
public/data/poems_with_more_info.tsv
```

هیچ پیوندی به محل بیرونی فایل خام در رابط سایت، صفحات پژوهش یا متادیتای عمومی نمایش داده نمی‌شود.

## استقرار روی Vercel

پروژه را در GitHub قرار دهید و در Vercel Import کنید. تنظیمات در `vercel.json` ثبت شده‌اند:

```text
Framework: Vite
Build Command: npm run build
Output Directory: dist
Node.js: 22
```

برای دامنهٔ اختصاصی:

```text
SITE_URL=https://your-domain.example
```

راهنمای استقرار در [`docs/DEPLOY.md`](./docs/DEPLOY.md)، چک‌لیست SEO/GEO در [`docs/SEO_GEO.md`](./docs/SEO_GEO.md) و فهرست دقیق فایل‌های نسخهٔ ۷ در [`docs/GITHUB_UPDATE_FA.md`](./docs/GITHUB_UPDATE_FA.md) قرار دارد.

## معماری خروجی

```text
src/App.jsx                                  تجربهٔ تعاملی اصلی
src/chartOptions.js                          تنظیمات نمودارها، از جمله پرسش‌های عمومی
src/content/siteContent.js                   صفحات پژوهش، FAQ و واژه‌نامه
src/data/atlasData.json                      خروجی‌های تحلیلی اصلی
src/data/attributionResearch.json            پژوهش نهم و نتایج ممیزی انتساب
src/data/publicQuestionsResearch.json        پژوهش دهم و پاسخ‌های عمومی
scripts/generate_attribution_research.py     تولید تحلیل انتساب از TSV
scripts/generate_public_questions.py         تولید ده پرسش از TSV
scripts/postbuild.mjs                        تولید صفحات ایستا، Schema، sitemap و API
public/downloads/public-questions-analysis.csv خروجی عددی پرسش‌ها
public/og/og-public-questions.png            کارت اشتراک‌گذاری پژوهش دهم
dist/research/                               ده صفحهٔ پژوهشی پس از build
dist/api/ و dist/downloads/                  JSON و CSV تولیدشده
```

## URLهای مهم پس از build

- `/research/public-questions/` ده پرسش عمومی و روش کامل
- `/research/attribution/` پروندهٔ سنجش انتساب
- `/research/intertextuality/` نقشهٔ پیوندهای متنی
- `/research/` مرکز پژوهش‌ها
- `/data/` داده‌ها و خروجی‌های قابل دانلود
- `/methodology/` روش‌شناسی و محدودیت‌ها
- `/glossary/` واژه‌نامهٔ ساده
- `/api/public-questions.json` خروجی ساخت‌یافتهٔ پرسش‌ها
- `/downloads/public-questions-analysis.csv` همهٔ اعداد پرسش‌ها
- `/api/attribution.json` خروجی ساخت‌یافتهٔ پژوهش انتساب
- `/openapi.json` تعریف APIهای ایستا

## به‌روزرسانی داده

پس از تغییر فایل خام:

```bash
npm run data:generate
npm run data:research
npm run build
npm run seo:audit
```

فایل خام TSV در مخزن باقی می‌ماند، اما در بستهٔ تغییرات نسخهٔ ۷ دوباره کپی نشده است. تحلیل‌های منتشرشده فشرده‌اند.
