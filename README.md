# از شعر تا داده

**اطلس تعاملی و چندصفحه‌ای تحلیل داده‌های شعر فارسی — کاری از حسین کریمی**

«از شعر تا داده» نه مطالعهٔ پژوهشی را برای مخاطب عمومی، پژوهشگر ادبیات و داده‌کاو در یک تجربهٔ بصری فارسی ارائه می‌کند. نسخهٔ ۶ علاوه بر بازطراحی تجربهٔ کاربری، یک آزمایشگاه داده‌محور برای ممیزی انتساب شعر، پروندهٔ خیام، اولویت‌بندی اشعار منتسب حافظ و بررسی روندهای فکری دوره‌ها دارد.

## فصل‌های پژوهش

1. رودخانهٔ تحول مضامین شعر فارسی
2. تولد، خاموشی و دگرگونی استعاره‌ها
3. نقشهٔ پیوندهای متنی و شباهت شاعران
4. تشخیص سدهٔ شعر با هوش مصنوعی
5. اثر انگشت سبکی و کشف شعرهای نامتعارف
6. مقایسهٔ تکامل غزل، قصیده، رباعی و مثنوی
7. جغرافیای تخیل و مهاجرت شعر فارسی
8. نیمه‌عمر واژگان در شعر فارسی
9. سنجش انتساب شعر با شواهد زبانی، فکری و تاریخی

## ویژگی‌های نسخهٔ ۶

- ناوبری گروه‌بندی‌شده و مسیر مطالعهٔ روشن‌تر به‌جای منوی تخت و شلوغ
- حالت «مطالعهٔ ساده» و «جزئیات پژوهشی» برای مخاطبان متفاوت
- واژه‌نامهٔ درون‌صفحه‌ای و توضیح عمومی اصطلاحات دشوار
- استفاده از «پیوند متنی» و «شاخص شباهت متنی» در رابط عمومی و حفظ اصطلاح تخصصی در روش‌شناسی
- نقشهٔ پیوندهای متنی با آستانهٔ قابل تنظیم، تمرکز روی شاعر، دو چیدمان و راهنمای نوع شاهد
- آزمایشگاه انتساب با پنج لایهٔ شاهد: واژگان، جهان فکری، سبک، بستر تاریخی و نسخه‌ها
- پرونده‌های داده‌محور خیام، حافظ و تحلیل سیستمی روندهای دوره‌ای
- تفکیک روشن «اولویت بازبینی» از «حکم اصالت» و نمایش محدودیت نسخه‌شناختی داده
- ممیزی خودکار نثر مخلوط، متن‌های تکراری و واحدهای بسیار کوتاه
- خروجی CSV ممیزی و JSON پژوهش انتساب
- صفحات مستقل برای نه پژوهش، همهٔ ۶۷ شاعر، ۱۱ مضمون، ۱۰ خانوادهٔ استعاری و ۱۳ سده
- متن و جدول معادل برای نمودارها، قابل خواندن بدون JavaScript
- Schema.org، sitemap، RSS، JSON Feed، OpenSearch، OpenAPI، گراف دانش و خروجی‌های GEO
- رابط راست‌به‌چپ، اعداد فارسی، حالت روشن و تاریک و طراحی واکنش‌گرا

## اجرای محلی

نیازمند Node.js نسخهٔ ۲۲ و Python 3:

```bash
npm install
npm run dev
```

ساخت نسخهٔ تولیدی و ممیزی SEO/GEO:

```bash
npm run build
npm run seo:audit
npm run preview
```

## تولید دوبارهٔ تحلیل انتساب

اسکریپت جدید فایل پنج‌ستونهٔ `public/data/poems_with_more_info.tsv` را می‌خواند و دو خروجی فشرده تولید می‌کند:

```bash
npm run data:attribution
```

خروجی‌ها:

```text
src/data/attributionResearch.json
public/downloads/attribution-corpus-audit.csv
```

این تحلیل برای پالایش پیکره، کشف هم‌پوشانی‌ها و اولویت‌بندی بازبینی طراحی شده است. چون فایل TSV شناسه، تاریخ و تبار نسخه‌ها را ندارد، خروجی هیچ احتمال ساختگی برای «اصالت نسخه‌شناختی» تولید نمی‌کند.

## استقرار روی Vercel

پروژه را در GitHub قرار دهید و در Vercel Import کنید. تنظیمات در `vercel.json` ثبت شده‌اند:

```text
Framework: Vite
Build Command: npm run build
Output Directory: dist
Node.js: 22
```

برای دامنهٔ اختصاصی:

```text
SITE_URL=https://your-domain.example
```

راهنمای استقرار در [`docs/DEPLOY.md`](./docs/DEPLOY.md)، چک‌لیست SEO/GEO در [`docs/SEO_GEO.md`](./docs/SEO_GEO.md) و فهرست دقیق فایل‌های نسخهٔ ۶ در [`docs/GITHUB_UPDATE_FA.md`](./docs/GITHUB_UPDATE_FA.md) قرار دارد.

## معماری خروجی

```text
src/App.jsx                              تجربهٔ تعاملی اصلی
src/components/Chart.jsx                 بارگذاری تنبل نمودارها
src/content/siteContent.js               محتوای صفحات پژوهش، FAQ و واژه‌نامه
src/data/atlasData.json                  خروجی‌های تحلیلی اصلی
src/data/geographyResearch.json          پژوهش هفتم
src/data/lexicalResearch.json            پژوهش هشتم
src/data/attributionResearch.json        پژوهش نهم و نتایج ممیزی انتساب
scripts/generate_attribution_research.py تولید تحلیل انتساب از TSV اصلی
scripts/postbuild.mjs                    تولید صفحات ایستا، Schema، sitemap و API
public/downloads/attribution-corpus-audit.csv خروجی ممیزی قابل دانلود
dist/research/                           نه صفحهٔ پژوهشی پس از build
dist/api/ و dist/downloads/              JSON و CSV تولیدشده
```

## URLهای مهم پس از build

- `/research/attribution/` پروندهٔ سنجش انتساب
- `/research/intertextuality/` نقشهٔ پیوندهای متنی
- `/research/` مرکز پژوهش‌ها
- `/poets/` نمایهٔ همهٔ شاعران
- `/data/` داده‌ها و خروجی‌های قابل دانلود
- `/methodology/` روش‌شناسی و محدودیت‌ها
- `/glossary/` واژه‌نامهٔ ساده
- `/api/attribution.json` خروجی ساخت‌یافتهٔ پژوهش انتساب
- `/downloads/attribution-corpus-audit.csv` ممیزی پیکره
- `/openapi.json` تعریف APIهای ایستا

## به‌روزرسانی داده

پس از تغییر فایل خام:

```bash
npm run data:generate
npm run data:attribution
npm run build
npm run seo:audit
```

فایل خام TSV در مخزن باقی می‌ماند، اما در بستهٔ تغییرات نسخهٔ ۶ دوباره کپی نشده است. تحلیل‌های منتشرشده فشرده‌اند و هیچ پیوندی به محل بیرونی فایل خام در رابط سایت نمایش نمی‌دهند.
